def chunk_text(text, chunk_size=CHUNK_SIZE, overlap=OVERLAP):
    words = text.split()
    chunks = []
    i = 0
    while i < len(words):
        chunk = " ".join(words[i:i + chunk_size])
        chunks.append(chunk)
        i += chunk_size - overlap
    return chunks

ANSWER: Several related accuracy tradeoffs surfaced:

- Metric choice vs class imbalance
  - Accuracy/ROC-AUC can be misleading under severe imbalance; the project emphasized Precision/Recall AUC and F1 for the minority (churn) class instead of raw accuracy.
  - Final reported ROC-AUC = 0.836, but the operational metric was F1 for churners (F1 = 0.63).

- Imbalance-handling method vs apparent performance
  - Different resampling/weighting strategies (SMOTE at different ratios, class‑weighting, boosting weights) change what the model “sees” during training. An unfair comparison (unequal imbalance handling) would quietly favor tree models.
  - The write‑up warns of the “SMOTE trap”: aggressive oversampling can boost ROC/AUC and recall but destroy precision (many false positives) unless thresholded appropriately.

- Precision vs recall (decision threshold)
  - The default 0.5 cutoff was not appropriate. The team swept thresholds and chose 0.40 to maximize F1 for churners, explicitly trading off precision and recall to meet an operational objective (precision‑driven target rather than blind 0.5).

- Simplicity vs complexity / interpretability
  - Logistic Regression (the simplest model) won on evidence (better ROC‑AUC here) because churn was largely driven by linear factors (tenure, contract, monthly charges). That choice accepted a simpler, more interpretable model rather than a more complex tree/boosting model whose apparent gains could come from uneven preprocessing.

- Implementation correctness vs accuracy
  - A production bug (pandas.get_dummies(drop_first=True) on a single-row DataFrame) caused categorical inputs to be ignored for single-row predictions — an accuracy/validity hit that only surfaced with output verification.

In short: the project balanced metric selection, imbalance-handling, and threshold setting (precision vs recall) to produce honest, operationally useful accuracy rather than inflated numbers from careless preprocessing or defaults.
